### Пояснение:
- **MainActivity** - точка входа, запускает `App.kt`
- **App.kt** - управляет основным навигационным хостом
- **StartFlowNavigation** - модуль навигации для аутентификации
- **MainFlowNavigation** - модуль навигации для основного функционала приложения
- **AuthScreen** - экран входа с текстовыми полями и кнопкой
- **MainScreen** - главный экран с нижним меню и внутренней навигацией
- **BottomNavigationBar** - компонент нижнего меню (только отображение и отправка действий)
- **InnerMainFlowNavigation** - внутренняя навигация для экранов нижнего меню (управляет переходами)
- **MainScreenViewModel** - обрабатывает действия и отправляет события навигации
- **Экраны** - три основных экрана: Техника, Добавить, Кабинет
